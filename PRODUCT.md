# Certification gallery

Joey Wilkes’s public credential gallery serves recruiters and visitors reviewing professional learning in cloud, artificial intelligence, FinOps, and sustainability.

The homepage leads with an interactive orbital reel of 17 primary certifications and courses. The primary collection lets visitors search, filter by category and completion status, and open permanent credential pages or issuer evidence. Ten reel records carry exact issuer-backed completion dates; undated records retain their existing factual status.

A secondary collection contains 17 Google Skills badges and 19 LinkedIn Learning course completion certificates. It has independent search and native disclosures, with original certificate PDFs, earned dates and official course context. These entries stay outside the reel. Decision Intelligence is first with five favorite stars; Forecasting and Vector Search carry Joey’s personal ratings, separate from issuer metadata.

The gallery is a static, self-contained GitHub Pages website in `JoeyWilkes12/certifications-site`. Its theme aligns with Joey’s portfolio in `JoeyWilkes12/personal-websites`, release `replit/autoscale-2026-10-03-v1.0.1`, app `2026-10-03_v1.0.1`.

The theme port preserves the established gallery composition, credential facts, original artwork, crop rules, orbit controls, keyboard access, mouse dragging, touch swiping, navigation, appearance preference and reduced motion. Both desktop and mobile visitors must retain readable content without horizontal overflow. JavaScript-disabled visitors can inspect the pre-rendered collections, native certificate disclosures and permanent pages.

Content sources and personal ratings are recorded in `data/`. PDF source hashes remain part of the static regression checks. This repository must publish without access to the parent workspace’s shared assets.
